# 801课件上传工具

局域网内收集课件的 Windows 桌面工具。程序在托盘运行，内置 Web 服务，老师在手机或电脑浏览器里即可把课件上传到服务器上的指定目录，不需要安装客户端。

## 功能

- 浏览器上传：同一局域网内扫码或输入网址访问，支持批量选择、拖拽文件
- 上传队列：显示进度、速度与剩余时间，失败可重试，大文件分块上传
- 课件目录：多个课件目录并列显示，支持新建、重命名、删除文件夹
- 文件冲突：同名文件可选择跳过、覆盖或重命名，并可对后续文件沿用同一选择
- 讲者名单模式：为当前文件夹录入讲者名单，自动建好每人的文件夹，按「已上传 / 未上传」展示，可一键查看状况截图并复制名单，把文件拖到对应卡片即上传到该讲者目录
- 在线预览：图片、音视频、PDF、文本等常见格式直接在浏览器中查看
- 下载：文件可直接下载，文件夹可在后台打包成 zip 下载，显示打包进度、可随时取消
- 磁盘占用：随时查看服务端各磁盘的剩余空间，打包前自动检查空间是否足够
- 访问密码：可选设置，未设置时局域网内可直接访问
- 二维码：一键显示访问地址的二维码，方便手机扫码

## 环境要求

- Windows 7 SP1 及以上
- .NET Framework 4.8

## 使用

1. 运行 `801CoursewareUploader.exe`，程序在系统托盘常驻。
2. 在设置中指定课件目录与端口（默认 `41004`）。
3. 局域网内的设备用浏览器访问 `http://服务器IP:41004`，或直接扫描程序显示的二维码。

上传的文件保存在设置里指定的课件目录中，程序本身不额外复制一份。

## 编译

使用 .NET Framework 4.8 与 MSBuild：

```bat
C:\Windows\Microsoft.NET\Framework\v4.0.30319\MSBuild.exe 801CoursewareUploader.csproj -p:Configuration=Release
```

编译产物位于 `bin\Release\801CoursewareUploader.exe`。网页资源以嵌入资源方式打包进 exe，修改 `web\` 下的文件后需要重新编译。
