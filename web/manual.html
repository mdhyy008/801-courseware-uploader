1简介

801 课件上传工具在一台电脑上启动后，会开启一个本地网页服务。同一局域网内的手机、平板、其他电脑打开该网页，就可以把课件直接上传到这台电脑的指定目录，也可以浏览、重命名、删除、预览文件，以及整文件夹打包下载。

电脑端程序负责添加目录、启动服务和系统级设置；网页端负责日常上传和管理。

局域网上传

手机、平板、电脑扫码或输入地址即可上传，支持整个文件夹拖拽。

文件管理

浏览、预览、重命名、删除、新建文件夹，文件夹可打包下载。

屏幕控制

在网页里查看并操作服务端电脑，远程切 PPT、点下一页。

讲者名单模式

按讲者自动分文件夹归档，状况截图核对谁还没传。

2快速开始

  1. 1
    在要保存课件的电脑上打开「801课件上传工具」。
  2. 2
    点击右上角的「添加目录」，选择课件保存文件夹，可重复添加多个目录。
  3. 3
    记下窗口里显示的「上传地址」，例如 http://192.168.1.20:41004/。
  4. 4
    手机或其他电脑连接同一个局域网，在浏览器输入该地址；也可以直接点二维码按钮，用手机扫码访问。
  5. 5
    如果设置了访问密码，先输入密码登录。
  6. 6
    点「上传」选择文件，或把文件、文件夹直接拖进网页，即可开始上传。

设置调整并发上传数、文件白名单、访问密码、隐藏文件显示、屏幕控制开关，查看并清理上传缓存。

4上传文件

两种上传方式

按钮选择

点右上角「上传」按钮，选择一个或多个文件。

拖拽上传

把文件或整个文件夹拖进网页，出现「松手上传」提示后松手；文件夹结构会保留。

上传队列

  • 页面底部显示上传队列：进度、速度、成功/失败状态。可单独取消某个文件。
  • 「清除已完成」只清掉已完成记录；「清空记录」清空整个列表（不会删除已上传文件）。
  • 上传面板可以收起，减少遮挡。

同名与重复文件

  • 目标目录已有同名文件时，会弹出「同名文件」对话框，可选 覆盖、改名保存 或 跳过。
  • 如果新上传文件与已有文件内容完全相同（哈希一致），会提示「重复文件」，可选 改名保存 或 跳过。
  • 勾选「后续文件保持一致」后，本次操作中遇到同类情况会按同一选择自动处理。

文件类型限制

只有白名单内的扩展名允许上传和显示。默认包含文档、表格、演示、PDF、图片、音视频、压缩包和网页等常见格式；需要增加或减少类型，在电脑端「设置 → 文件白名单」里修改（逗号分隔）。

5文件与文件夹管理

  • 目录切换：顶部标签切换课件目录。
  • 浏览：左侧目录树和面包屑可进入子文件夹；支持按时间、名称、大小排序和分页。
  • 预览：图片、视频、音频等可直接在网页中预览。
  • 打开：让服务端电脑用默认程序打开该文件（适合上课时直接投屏）。
  • 重命名 / 删除：对文件或文件夹操作。删除会移入服务端电脑的回收站，可到回收站找回。
  • 新建文件夹：在当前位置新建；也可对文件夹重命名、删除。
  • 打包下载：文件夹可打包成压缩包下载，底部「下载队列」显示进度，完成后自动开始下载；可清空下载记录。
  • 磁盘空间：顶栏磁盘按钮可查看各磁盘剩余空间，顶栏进度条显示占用/剩余概览。

6讲者名单模式

  1. 1
    打开工具栏的「讲者名单模式」开关。
  2. 2
    编辑名单：每行一个名字，保存后生效。
  3. 3
    之后上传文件时，会先选择讲者，上传内容自动放进以该讲者命名的子文件夹。
  4. 4
    「状况截图」按钮会把名单与每个名字的文件夹状态生成一张截图，可复制其中的文本，方便核对谁还没传。

7屏幕控制

顶栏的「屏幕控制」按钮可查看并操作服务端电脑。它适合远程切 PPT、打开文件、点下一页等操作。

  • 显示器：多显示器时可在标题栏左侧下拉选择。
  • 传输方式：差分 延迟最低、MJPEG 兼容性好、WebRTC 画质与流畅度均衡；卡顿时可切换试试。
  • 鼠标：支持单击、右键、按住拖动。
  • 键盘：弹窗处于打开状态时，键盘和快捷键会转发到被控电脑（如 Esc、方向键、Ctrl 组合键）；点标题栏的「查看快捷键」可查看全部可用按键。
  • 最大化：用右上角最大化按钮切换全屏显示。
  • 最小化：缩成网页里的小浮窗，浮窗只做预览，提示「请展开使用」；点展开按钮回到控制弹窗，点关闭则彻底断开控制。
  • 权限模式：弹窗标题会显示当前权限，如「屏幕控制（管理员）：电脑A」。普通权限下，任务管理器等管理员窗口无法点击操作。
  • 远程提权：普通权限时弹窗顶部显示「提权重启」按钮。点击后被控电脑会弹出 UAC 确认，需在那台电脑上点「是」；程序会以管理员身份重启，网页 5 秒后自动刷新，重新登录后即可操作管理员窗口。取消确认则程序保持原样。

注意：浏览器占用的一些系统级快捷键（如 Ctrl+W、Ctrl+T、Ctrl+N、Alt+F4、Windows 键）无法转发给被控电脑，这是浏览器限制。

提示：UAC 确认框、锁屏界面和 Ctrl+Alt+Del 由 Windows 单独保护，任何权限下都无法在网页中查看或操作。

8设置项说明

设置说明
并发上传数同时上传的文件数量，默认 3。网络好可适当调高，网络差或设备多时调低更稳。
文件白名单允许的扩展名，逗号分隔；不在列表中的文件不会显示、不能上传。
访问密码设置后打开网页需登录；留空保存表示无密码。忘记密码可直接在这里重设。
显示隐藏文件是否在网页列表中显示以点开头的隐藏文件。
屏幕控制关闭后网页不再显示屏幕控制入口。
管理员权限显示当前是否以管理员运行；普通权限时可点「以管理员身份重启」，重启后才能操作任务管理器等管理员窗口。
上传缓存上传过程中的临时文件缓存，显示当前占用，可点「清理」释放；不影响已上传完成的文件。

9数据与删除

  • 程序数据（配置、索引、上传缓存）位于程序目录下的 data 文件夹，不会写到系统盘临时目录。
  • 被删除的文件和文件夹会进入 Windows 回收站，可在回收站找回。
  • 配置保存在 data/config.json；如无特殊需要，不建议手动修改。

10排障

  • 确认两台设备连接的是同一个局域网（同一路由器 / 同一 WiFi，不能一台连 WiFi 一台连热点）。
  • 确认电脑端程序正在运行，窗口里显示的是可用上传地址而不是「服务未启动」。
  • 首次运行程序时如弹出管理员授权（UAC），必须点「是」，否则局域网访问和防火墙规则无法生效。
  • IP 变化后点电脑端「刷新」按钮，再重新获取地址或二维码。
  • 公司或校园网络可能启用了「设备隔离 / AP 隔离」，会禁止设备互访，请联系网管放行。
  • 如果开了 VPN、虚拟网卡或多个网卡，可能拿到错误 IP，可临时关闭 VPN 后刷新地址。

  • 默认端口是 41004，可能被其他程序占用；关闭占用该端口的程序后重启本程序。
  • 防火墙或安全软件可能拦截，首次运行请允许程序通过防火墙。
  • 极端情况下可修改 data/config.json 中的 Port 后重启；重启时若提示管理员授权请同意，以便重新注册端口与防火墙。

  • 输入电脑端当前设置的访问密码；忘记密码就在电脑端「设置」里重新设置（留空即取消密码）。
  • 密码修改后，已打开的旧页面需要重新登录。

  • 先确认服务端电脑磁盘空间充足（顶栏磁盘按钮查看）。
  • 确认文件扩展名在白名单内，否则不会允许上传。
  • 大文件、WiFi 信号弱、多设备同时上传都可能导致慢或中断；可降低「并发上传数」，改用有线网络重试。
  • 文件正被其他程序占用（如正在播放的视频）时可能读写失败，关闭占用程序后再传。
  • 重新上传同名文件时选择「覆盖」或「改名保存」，避免因「跳过」误以为上传成功。

  • 请把文件拖到网页内容区域内再松手，页面出现「松手上传」提示后才有效。
  • 部分浏览器对拖拽文件夹支持有限，可改用「上传」按钮选择文件夹。

  • 文件夹过大时需要先压缩，耗时较长；保持页面打开，等下载队列完成。
  • 确认服务端磁盘有足够剩余空间。
  • 可取消后重试；反复失败时先删减文件夹内容或分次下载。

  • 被控电脑处于锁屏或息屏时无法截取画面，请先解锁并保持屏幕点亮。
  • 在标题栏切换传输方式（差分 / MJPEG / WebRTC）试试；全屏高分辨率下可适当降低窗口大小。
  • WebRTC 依赖 UDP 通信，若被防火墙拦截会自动回退，必要时在电脑端防火墙放行程序。
  • 多显示器时确认选择的是正在显示内容的那个显示器。

  • 浏览器保留的系统快捷键无法转发（Ctrl+W、Ctrl+T、Ctrl+N、Alt+F4、Windows 键等），请在被控电脑上直接操作这些键。
  • 中文输入需要在被控电脑上切换到中文输入法，网页只负责转发按键。
  • 输入焦点在网页输入框里时不会转发按键，先点一下画面再按键。

  • 把手机相机对准二维码并保持稳定，或直接用浏览器手动输入上传地址。
  • 确认扫码设备与服务端电脑在同一局域网。

  • 程序是单实例运行，可能已经在右下角托盘里；双击托盘图标即可打开主界面。
  • 要彻底退出，右键托盘图标选「退出程序」。
